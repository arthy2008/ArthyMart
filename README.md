# ArthyMart

A multi-seller e-commerce marketplace web application built with Java Servlets, JDBC, Apache Tomcat, and H2 Database.

## Features
- User registration and role-based login (Buyer, Seller, Admin)
- Product management for Sellers
- Product browsing, filtering, and cart management for Buyers
- Checkout and order history tracking
- Admin user and listing moderation
- Product reviews and ratings

## Tech Stack
- **Backend:** Java 17, Servlet API (javax.servlet.*), JDBC
- **Database:** H2 Database, HikariCP Connection Pooling
- **Frontend:** JSP, JSTL, Vanilla JavaScript
- **Build & CI:** Apache Maven, GitHub Actions
